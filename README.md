A high-performance personal portfolio and interactive CMS management portal built with **React**, **Vite**, and **Tailwind CSS**.

## 🌟 Key Features

- **Executive Engineering Portfolio**: Highlighting 12+ years in FinTech, core banking systems, microservices, and team leadership.
- **Built-in Live CMS Dashboard (`/rotha`)**:
  - Live in-browser editing of all profile data, headlines, services, banking projects, timelines, degrees, and skills.
  - JSON backup import & export.
  - Instant live preview with one-click hide/minimize toggle.
  - Protected with session authentication (`rotha.` / `rotha@123`).
- **Fully Responsive & Touch-Optimized**: Native app experience on mobile devices with smooth swipe navigation and zero iOS input zoom.
- **Bilingual & Multi-Language Support**: English and Khmer (ភាសាខ្មែរ).

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Open Admin CMS Dashboard
Navigate to [http://localhost:3000/rotha](http://localhost:3000/rotha) or press `Ctrl + Shift + A`.

### 4. Build for Production
```bash
npm run build
```

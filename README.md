# Web Portfolio — Design That Builds Brands

A high-converting, modern designer portfolio website created directly from the provided UX/UI reference design.

![Design Preview](https://images.unsplash.com/photo-1507003211169-0a1dd7228f2d?auto=format&fit=crop&w=600&q=80)

---

## 🌟 Key Features

- **Exact UI/UX Replication**:
  - **Floating Pill Navbar**: Dark pill navigation with active tab pill highlight and interactive *"Let's Talk"* button with directional arrow badge.
  - **Hero Section**: `OPEN FOR SELECTED PROJECTS` pill tag, bold headline with orange dot accent, dual CTAs (*"View My Work"* & *"Hire Me →"*), circular orange backdrop cutout, and floating *5+ Years Experience* badge.
  - **"What I Do" (Services)**: Dark rounded container with 4 interactive service cards (UI/UX Design, Web Design, Brand Identity, Graphic Design) featuring custom orange iconography and directional arrow micro-interactions.
  - **"Selected Projects" (Featured Work)**: 3-column project showcase with category tags, custom typography, image zoom effects, and a centered *"View All →"* button.
  - **Metrics & Stats Bar**: 4-counter row with custom icons (Years Experience, Projects Completed, Happy Clients, Countries Worked).
  - **"Trusted by Great Clients" (Testimonials)**: Warm-tinted cards with 5-star ratings, quotes, client avatar cards, and carousel controls.
  - **"Let's Work Together" Banner**: Full-width high-contrast orange CTA banner with instant inquiry trigger.
  - **Footer**: 4-column layout with social media circular buttons (X, Instagram, LinkedIn, GitHub, Dribbble, Pinterest), quick links, services directory, contact details, and legal copyright bar.

- **Interactive Modals & Tools**:
  - **Inquiry & Booking Modal**: Allows visitors to select services, pick estimated budgets, and send inquiries.
  - **Project Case Study Modal**: Displays client brief, challenge overview, deliverable tags, and live preview links.
  - **Portfolio Archive Explorer**: Filter projects by categories (All, Graphic Design, Brand Identity, UI/UX, Web Design).
  - **One-Click Profile Switcher**: Easily switch between the **Talmeez (Exact UI Screenshot)** preset and **Wife's Portfolio (Elena Vance)** preset, or customize names, titles, and photos directly in real time.

## 🚀 Getting Started

### 1. Run Development Server
```bash
npm run dev
```
The site will start locally at `http://localhost:5173/`.

### 2. Build for Production
```bash
npm run build
```
Production-ready files will be generated in the `dist/` directory.

## 🎨 Customizing Content

All data (profile details, services, projects, stats, testimonials, and footer links) is neatly organized in:
[`src/data/portfolioData.js`](file:///d:/My%20Wife-%20Portfolio/src/data/portfolioData.js)

You can easily replace the name, avatar photo, project images, and contact links to personalize the portfolio.
